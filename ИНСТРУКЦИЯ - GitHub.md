# «Баня» — исходный проект для GitHub

Готовый адаптивный лендинг творческой мастерской «Баня».

## Как запустить локально

1. Установите Node.js 22 или новее.
2. В терминале откройте эту папку.
3. Выполните `npm install`.
4. Выполните `npm run dev`.
5. Откройте адрес, показанный в терминале.

## Как загрузить на GitHub

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него всё содержимое этой папки, включая скрытый файл `.gitignore`.
3. Для публикации подключите репозиторий к Vercel или Cloudflare Pages.
4. Build command: `npm run build`.
